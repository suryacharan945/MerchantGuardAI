On a held-out test set of 1398 transactions (28 fraud), the supervised LightGBM classifier reached 0.9241 AUROC. The hybrid ensemble (LightGBM weighted 0.95 + combined Autoencoder/IsolationForest novelty signal weighted 0.05, calibrated via Platt scaling) reached 0.9345 AUROC — a modest lift attributable mainly to the small, correlated unsupervised contribution. Given only 28 fraud examples in the test set, this difference is not strongly conclusive on its own; the ensemble's primary value is architectural robustness against fraud patterns unlike the 4 types used to generate this synthetic dataset, which a same-distribution test set cannot fully demonstrate either way.
